# 网申简历自动填充

一个本地优先的浏览器扩展：把你自己的简历档案存在本机，在企业网申表单上一键填入，识别不了的字段明确标出来让你自己补。**不上传任何数据，不自动提交。**

> 适用于 Chrome / Edge 110 及以上（Manifest V3）。纯 JavaScript，无构建步骤、无后端、无 npm 依赖。

---

## 三条硬性承诺

- **不联网**（除了你主动开启的「大模型辅助」）
- **数据只在你自己的浏览器里**，不上传、不同步
- **永远不会自动提交**，填完你自己检查、自己点提交

---

## 安装（开发者模式，约 1 分钟，只需做一次）

1. 克隆本仓库，得到 `extension/` 目录。
2. 地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）。
3. 打开页面右上角的 **「开发者模式」** 开关。
4. 点左上角 **「加载已解压的扩展程序」**，选中仓库里的 **`extension` 文件夹本身**。
   ⚠️ 选中它的父目录会报「清单文件缺失」，一定要选中 `extension` 这一层。
5. 列表里出现「**网申简历自动填充**」即成功。

> 浏览器会提示「读取和更改您在所有网站上的数据」——这是自动填表类扩展必须的权限（要能读到页面输入框）。扩展里没有任何常驻联网代码。

---

## 录入你自己的信息

点工具栏扩展图标 → 面板底部「**编辑档案**」。

- 左侧按板块分组（基本信息 / 教育经历 / 实习经历 / 项目经历 …），带「＋ 添加一段」的可加多段。
- **自动保存**，没有保存按钮，右上角显示「已保存」。

**不想手打？用模板 + 任意大模型：** 设置页点「**下载导入模板**」→ 把模板和你的简历一起发给任意大模型（ChatGPT / DeepSeek / Kimi 均可）→ 让它照模板整理成 JSON → 设置页「**导入 JSON**」。导入时会告诉你哪些值没法识别、哪些必填还空着。

---

## 在招聘网站上用

1. 打开网申表单页，**先 F5 刷新一次**（让扩展脚本注入）。
2. 页面**右下角**出现「**填充简历（N 项）**」按钮（原始输入框 ≥ 6 个、能识别 ≥ 3 个字段才出现）。
3. 点它 → 自动扫描 → 匹配 → 填写。
4. **按颜色核对：**

   | 颜色 | 含义 | 你要做的 |
   |---|---|---|
   | 🟢 绿 | 很有把握 | 扫一眼即可 |
   | 🟡 黄 | 填了但不确定 | **请核对** |
   | 🔴 红 | 没填上 | 手动补（点红点选字段，或新建自定义列） |

**页面上已经有内容的字段不会被覆盖。** 官网自己解析出来的、或你已经手填的内容，扩展会原样保留，并在报告里单独标为「**已保留**」（灰色角标）。确实想改的话，点那个灰点手动指定字段即可（手动指定允许覆盖）。

**识别不出的字段怎么办：** 点红点 → 字段选择器里选档案字段，本次指定会按当前域名记住，下次自动生效。页面上找不到合适选项时，可在选择器底部「＋ 新建自定义列」，一次点击完成建列 + 写值 + 记住映射，以后全局自动填。

---

## 可选：开启大模型辅助（L3）

**默认关闭**，不开就一个网络请求都不发。开启后，规则匹配不出的「怪字段」会交给大模型推断，需要你自己的 API Key（支持任意 OpenAI 兼容接口，含本地 Ollama）。

它在扩展里塞了两道闸，确保档案不外泄：

- 姓名、手机号、身份证号、邮箱等 **11 个敏感字段，连字段名都不会出现在请求里**。
- 你档案里的**真实值一个都不会发出去**，只发页面标签、输入框类型和下拉选项。

---

## 隐私与安全

- 所有数据存在浏览器的 `chrome.storage.local`，只有档案、手动映射、自定义列定义和大模型配置，**没有 cookie、没有埋点、没有统计**。
- 代码全在 `extension/` 里，纯 JS、未压缩混淆，可用记事本直接打开查看。
- 想确认有没有联网代码：在 `extension` 里搜 `fetch(`，只有 `background/sw.js` 里那一处是真正的网络请求，就是「大模型辅助」，且默认关闭时不会执行。
